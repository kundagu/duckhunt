# Тренажёр стендовой стрельбы

Браузерная игра-тренажёр: поле, горизонт, небо и летящие тарелочки. Реализация на чистом JavaScript + Canvas 2D, без зависимостей.

## Запуск

Откройте `index.html` в браузере (двойным кликом достаточно), либо через локальный сервер:

```
npx serve .
```

## Управление (по умолчанию, переназначается в меню)

| Действие       | Клавиша        |
|----------------|----------------|
| Прицеливание   | Пробел (удерживать) |
| Выстрел        | ЛКМ            |
| Перезарядка    | ПКМ            |
| Пауза          | Esc            |

Чувствительность мыши, скорость тарелочек (10–80 км/ч, по умолчанию 72),
привязки кнопок, звук и подсказки (куда целиться — кольцо упреждения у
каждой видимой цели; куда попала дробь — оранжевая отметка центра дробового
пятна плюс жёлтое призрачное кольцо — точка подсказки упреждения (куда
целиться) в момент выстрела; обе
отметки плавно угасают в течение 3 с и переживают новые выстрелы) сохраняются
в `localStorage`.

## Механика

- Камера вращается движением мыши (захват курсора), перемещений нет.
- Тарелочки 22×5 см (увеличены вдвое для удобства тренировки): летят вдвое
  медленнее настройки скорости (визуально вдвое медленнее прежних
  70–75 км/ч); цель живёт, пока не вылетит из 30-метровой зоны (не
  исчезает раньше — ни по времени, ни при пролёте за спиной стрелка),
  все налёты начинаются в секторе видимости стрелка ±45° от направления
  взгляда. Траектории: на стрелка (пролёт через голову), от стрелка,
  касательная под углами 90/60/30°, параллельно земле (в том числе над
  головой), взлёт под 10° и 30°.
- Дуплекс (вертикальная двустволка): ружьё появляется только при удержании
  прицеливания (просто поднимается, без зума) и выглядит как полукруг
  диаметром 20% высоты экрана с квадратной мушкой 1,5% высоты экрана сверху;
  от нижней части полукруга вниз до нижней границы экрана идёт прямоугольное
  цевьё шириной в диаметр полукруга. Точка прицеливания (верхушка с мушкой)
  (верхушка с мушкой) и ось выстрела опущены на 20% высоты экрана ниже
  центра — прицел ведётся мушкой, а не центром экрана. Отдачи нет.
  Первый выстрел — нижний ствол (получок), второй — верхний (чок);
  перезарядка всегда заряжает оба ствола полностью. Скорость дроби 175 м/с
  (вдвое медленнее прежних 350 — упреждение выросло), учитываются упреждение
  и просадка по траектории.
- Диаметр дробового пятна, см (разброс увеличен вдвое):

| Дистанция | Получок | Чок  |
|-----------|---------|------|
| 10 м      | 50      | 30   |
| 15 м      | 70      | 40   |
| 20 м      | 100     | 70   |
| 25 м      | 120     | 90   |
| 35 м      | 150–160 | 120–130 |

- Счёт: выстрелы — в левом нижнем углу, попадания — в правом.

## Файлы

```
index.html      — разметка (меню, пауза, canvas)
css/style.css   — стили
js/settings.js  — настройки в localStorage, меню, переназначение кнопок
js/input.js     — ввод (клавиши/кнопки мыши по привязкам)
js/targets.js   — генерация траекторий тарелочек, обломки
js/ballistics.js— пятно дроби, расчёт попаданий
js/render.js    — отрисовка сцены, оружия, HUD
js/game.js      — состояние игры, цикл, звук, захват курсора
```
